# ITNW-1425 Exam 3 Practice Website

A static, browser-only quiz website for Chapters 8, 9, and 10.

## Features
- Separate quizzes for Chapters 8, 9, and 10
- Combined quiz
- Top 100 review-focused questions
- Automatic grading and percentage score
- Review correct answers and mistakes
- Retry the full quiz or only missed questions
- Responsive layout for phones and desktops
- No backend, database, API keys, or environment variables required

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Create a new public GitHub repository (for example `itnw1425-exam3-practice`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Important source note
Chapter 8 Question 61 has no answer choices or marked correct answer in the supplied source PDF. It is shown as a note and excluded from scoring. The Top 100 set is selected from the supplied chapter questions based on overlap with the instructor's Exam 3 Review topics; it is not an official ranking supplied by the instructor.

## Privacy
All quiz state is handled in the browser. The website does not send answers to a server.
